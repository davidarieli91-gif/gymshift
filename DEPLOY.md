# GymShift — установка на сайт (GitHub + Vercel + Turso)

> Пошаговая инструкция. Всё по бесплатным тарифам, без платных подписок.
> Время: ~30–40 минут. Понадобятся аккаунты: **GitHub**, **Vercel** (vercel.com/fit-king — уже есть), **Turso** (создаём за 2 минуты через вход с GitHub).

---

## Как это устроено

| Часть | Где живёт | Цена |
|---|---|---|
| Сайт + API (Next.js) | **Vercel** (автодеплой из GitHub) | бесплатно (Hobby) |
| База данных (SQLite-совместимая) | **Turso** (облачный libSQL) | бесплатно (9 ГБ, хватит с запасом) |
| Код | **GitHub** (приватный репозиторий) | бесплатно |
| Обновления «в реальном времени» | авто-обновление раз в 15 секунд (поллинг) | — |

Локальный режим разработки (socket.io-realtime, файловая БД) продолжает работать как раньше — в песочнице ничего не меняется. На Vercel приложение автоматически использует поллинг: это уже проверено живьём.

## Шаг 1 — GitHub: залить код в репозиторий

Репозиторий уже создан: **https://github.com/davidarieli91-gif/gymshift** (приватный).

Код выкладываю я прямо из песочницы (репозиторий уже подготовлен: история
очищена одним «чистым» коммитом; из него удалены локальная база `db/custom.db`
с PIN-хэшами, `.env` и личные скриншоты — приватное в GitHub не попадёт).

Для доступа нужен **Personal Access Token** (2 минуты):

1. Откройте https://github.com/settings/personal-access-tokens/new
2. Token name: `gymshift-deploy` · Expiration: `7 days`
3. Repository access: **Only select repositories** → `gymshift`
4. Permissions → Repository permissions → **Contents: Read and write**
5. **Generate token** → скопируйте токен (`github_pat_…`) и пришлите мне в чат —
   я сам залью код и подтвержу.
6. После заливки кода токен можно сразу удалить: та же страница → **Delete**
   (если понадобится обновить код — сделаем новый, это 2 минуты).

## Шаг 2 — Turso: создать базу данных

1. Откройте https://turso.tech → **Get Started** → **Continue with GitHub** (тот же аккаунт — удобно).
2. После входа попадёте в панель app.turso.tech → **Create Database** (или + New Database):
   - Name: `gymshift`
   - Location/Region: **AWS EU West (Ireland)** — это ближайший к Израилю
     регион из доступных в бесплатном списке (Франкфурта там нет;
     разница с ним для 5 пользователей — доли секунды, не заметно)
   - Plan: **Free**
3. Откройте созданную базу → кнопка **Connect** (или «Show credentials») и скопируйте оттуда два значения:
   - **DATABASE_URL** — вида `libsql://gymshift-вашник.turso.io`
   - Токен: на странице базы найдите вкладку **Tokens** → **Create Token** (или в «Connect» будет команда `turso db tokens create gymshift`) → скопируйте **DATABASE_AUTH_TOKEN** (длинная строка, показывается один раз).

Итого у вас на руках 2 строки. Они понадобятся на шагах 3 и 4 — держите под рукой.

---

## Шаг 3 — создать таблицы в новой базе

В репозитории есть готовый скрипт. Выполните в терминале (в папке проекта), подставив свои значения:

```bash
DATABASE_URL="libsql://gymshift-вашник.turso.io" \
DATABASE_AUTH_TOKEN="ваш_токен" \
bun scripts/apply-schema.ts
```

Ответ должен закончиться: `✓ Schema applied — база GymShift готова на Turso.`

> Если хотите — просто пришлите эти две строки мне в чат, и я применю схему сам и сразу проверю базу.

**Альтернатива без терминала:** установить Turso CLI (`curl -sSfL https://get.turso.tech | bash`), затем `turso db shell gymshift < prisma/turso-schema.sql`.

## Шаг 4 — Vercel: импортировать проект и задать переменные

1. Откройте вашу ссылку https://vercel.com/new?teamSlug=fit-king
2. В списке «Import Git Repository» найдите `gymshift` → **Import**.
   (Если список пуст — нажмите «Adjust GitHub App Permissions» и дайте Vercel доступ к репозиторию.)
3. На шаге конфигурации **раскройте «Environment Variables»** и добавьте все 5 переменных:

| Name | Value | Откуда |
|---|---|---|
| `DATABASE_URL` | `libsql://gymshift-….turso.io` | Шаг 2 |
| `DATABASE_AUTH_TOKEN` | `eyJ…` | Шаг 2 (токен) |
| `AUTH_SECRET` | любая длинная случайная строка | сгенерируйте: `openssl rand -hex 32` (или попросите меня — сгенерирую) |
| `NEXT_PUBLIC_REALTIME` | `off` | фикс: на Vercel нет realtime-сервиса |
| `REALTIME_DISABLED` | `1` | фикс: сервер не тратит время на broadcast |

4. Нажмите **Deploy** и подождите 2–4 минуты.
5. (Необязательно, но приятно) Settings → Functions → **Function Region** →
   `Frankfurt (fra1)` — сервер будет ближе к Израилю и к базе в Ирландии.

> Важно: переменные нужно добавить ДО первого деплоя (или после добавления нажать Redeploy) — без `DATABASE_URL` сборка упадёт.

---

## Шаг 5 — первый запуск и настройка

1. Откройте адрес сайта вида `gymshift-….vercel.app` (Vercel покажет после деплоя).
2. Переключитесь на вкладку **Регистрация** и создайте аккаунт **דוד** (имя как в зале) + ваш PIN.
   → **Первый зарегистрированный автоматически становится админом** — он сможет добавлять/удалять тренеров.
3. Войдя как админ: «Все тренера» → добавьте Авиву, Игоря, Марину, Йоси (каждому PIN).
4. «Стандартные смены» → создайте недельный шаблон (вс–чт 7:30–12:00 / 12:00–17:00 / 17:00–22:30, пт 9:00–13:00 / 13:00–17:00, сб 8:00–17:00) → «Применить» на нужную неделю.
5. Кнопка **«Пригласить»** в шапке — ссылка WhatsApp тренерам; логин по имени + PIN.
6. Установите как приложение: на телефоне открыть сайт в Safari/Chrome → «Добавить на главный экран» (иконка GymShift уже настроена).

## Дальнейшие обновления

Любые изменения: я правлю код → `git push` → Vercel **сам** пересобирает и выкладывает сайт за ~2 минуты. Ничего нажимать не нужно.

## Частые вопросы

- **Сколько стоит?** 0 ₪: Vercel Hobby + Turso Free + приватный GitHub. Если зал когда-нибудь «вырастет» — апгрейды от $3–5/мес, но это не скоро.
- **Реального времени не будет?** На Vercel — обновление раз в 15 секунд (статус в подвале сайта: «онлайн/офлайн»). Это осознанное решение: socket.io-сервис требует постоянный сервер, а бесплатный serverless его не держит. Для смен в спортзале 15 секунд более чем достаточно.
- **Можно ли перенести текущие демо-данные?** Нет, и это правильно: продакшен начинается чистым. Шаблон стандартных смен создаётся за 5 минут руками.
- **Свой домен (например, gymshift.co.il)?** Vercel → Settings → Domains → Add. DNS-запись укажет Vercel; HTTPS включится сам.
- **Безопасность:** PIN хранится только как хэш (sha256), токен подписан `AUTH_SECRET`, личные календари фильтруются на сервере. Репозиторий приватный, база — только по токену.
